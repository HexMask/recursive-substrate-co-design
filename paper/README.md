# RSCD paper package

This directory contains the supplied public v0.1 paper in PDF and DOCX form,
the original `RSCD_David_Holbert_v0.1_package.zip`, and an expanded copy at
`source-package/`.

The supplied package also includes its publication README, researcher-outreach
note, and BibTeX bibliography. The paper is a conceptual proposal, not
experimentally validated research.
