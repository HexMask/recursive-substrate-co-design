# Recursive Substrate Co-Design (RSCD)

**Author:** David Holbert  
**Affiliation:** Independent Researcher  
**Version:** 0.1  
**Date:** September 30, 2026

## What this is

This repository/package contains a concept paper proposing **Recursive Substrate Co-Design (RSCD)**: a generational research framework in which an AI system designs a candidate computational substrate, a successor intelligence is trained natively within that substrate, and that successor is then used to search for the next substrate.

This is a **research proposal and conceptual framework**, not a report of completed RSCD experiments or empirical validation.

## Core idea

> Design the machine. Train the successor inside the machine. Let the successor design the next machine. Repeat.

The central research question is whether native training on successively machine-designed computational substrates can expand the computational design space reachable by later AI designers.

## Suggested public description

**Recursive Substrate Co-Design (RSCD)** is a proposed research framework connecting recursive AI improvement, hardware-software co-design, unconventional computing, automated learning-rule discovery, and native successor training. Rather than merely optimizing an AI for existing hardware or designing better hardware for an existing AI, RSCD asks what happens when each generation designs the computational environment in which its successor is trained.

## Suggested release note

Version 0.1 is an independent concept paper intended to invite criticism, prior-art identification, and collaboration. The novelty claim is deliberately narrow: the proposal concerns the *generational composition* of substrate discovery and native successor training, not the invention of the established fields it connects.
